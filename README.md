# Redmatch 2 SDK
Source code for the Redmatch 2 SDK, for the purpose of creating custom maps for [Redmatch 2](http://redmatchgame.com/). Some code is stripped for security reasons. Code contained in an `#if REDMATCH` block is only executed when running in the game itself.
