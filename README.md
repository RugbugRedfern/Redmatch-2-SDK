# Redmatch 2 Custom Map SDK
Source code for the Redmatch 2 Custom Map SDK, for the purpose of creating custom maps for [Redmatch 2](http://redmatchgame.com/). Some code is stripped for security reasons. Code contained in an `#if REDMATCH` block is only executed when running in the game itself.

You don't need to modify this code to make a map, but you can look at it to understand how the SDK works!

# Looking to make a map?
Start with the [Wiki](https://github.com/RugbugRedfern/Redmatch-2-SDK/wiki/Introduction)!

# Install
You can install the SDK through Unity's Package Manager by adding the package through this URL:
```bash
https://github.com/RugbugRedfern/Redmatch-2-SDK.git?path=/Assets/Redmatch%202%20Custom%20Map%20SDK#release
```
